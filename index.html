💡 Code Examples

Basic Date Creation

// Current date const now = new Date(); // Specific date const specificDate = new Date(2024, 0, 15); // Jan 15, 2024 // From ISO string const fromISO = new Date('2024-01-15T10:30:00Z'); // From timestamp const fromTimestamp = new Date(1705329000000);

Formatting with Intl

const date = new Date(); // Localized date const localeDate = new Intl.DateTimeFormat('en-US').format(date); // Custom format const customFormat = new Intl.DateTimeFormat('en-US', { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }).format(date);

Date Calculations

const date = new Date(); // Add 7 days const futureDate = new Date(date); futureDate.setDate(futureDate.getDate() + 7); // Start of month const startOfMonth = new Date(date.getFullYear(), date.getMonth(), 1); // Days between dates const daysDiff = Math.ceil((date2 - date1) / (1000 * 60 * 60 * 24));
